With Prof. Subhajit Dutta, IIT Kanpur — Jan 2024 to Apr 2024.

- Built a Seq2Seq model using LSTM for generating abstractive text summaries, leveraging encoder-decoder architecture.
- Implemented a preprocessing pipeline including text cleaning, tokenization, and Word2Vec embeddings for NLP tasks.
- Trained the model using the RMSprop optimizer with Sparse Categorical Cross Entropy loss for multi-class prediction.
